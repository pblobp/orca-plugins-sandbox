# Support

## Where to go

| You want to                          | Go to                                                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| Report a bug in one of these plugins | A [bug report](https://github.com/pblobp/orca-plugins/issues/new?template=bug-report.yml)               |
| Ask for a feature                    | A [feature request](https://github.com/pblobp/orca-plugins/issues/new?template=feature-request.yml)     |
| Propose a new plugin                 | A [new plugin proposal](https://github.com/pblobp/orca-plugins/issues/new?template=plugin-proposal.yml) |
| Report a security problem            | [SECURITY.md](SECURITY.md), never a public issue                                                        |
| Report a bug in Orca itself          | [github.com/stablyai/orca/issues](https://github.com/stablyai/orca/issues)                              |

A question about how to use a plugin: start with the plugin's README. If it does not answer the
question, open a feature request so the README can cover it.

## Is it the plugin or Orca?

If the problem happens with every plugin, or with Orca's own panels, it belongs to Orca. If it
happens only with one plugin from this repository, report it here. `orca plugin logs <plugin key>`
shows what the plugin printed and the errors its panels logged. Remove user names, host names and
paths before you paste it.

## What to expect

One person maintains this repository in their spare time. Answers are best effort, usually within a
week.
